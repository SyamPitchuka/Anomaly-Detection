# E1 robustness: seeds, held-out threshold, machine bootstrap (SMD)

Generated by `python experiments/e1_robustness.py`. E1 itself (`docs/results/e1.md`), the production models and
`data/scores` are unchanged; everything retrained here lives under `models/robust/` and `data/robust/`.
Runtime: seeds 6.7 min, holdout 3.6 min, bootstrap 0.0 min; total 10.4 min.

## Interpretation

**Does the E1 ranking survive? Partly.** All 6 retrained AE v2 runs (parts 1 and 2) stay below E1's PCA (0.554) and KMeans (0.596), best 0.526. Over machines the point order holds in most resamples (KMeans > PCA in 96.4%, KMeans > AE v2 in 93.9%, PCA > AE v2 in 72.3%; full order 69.0%), but the 95 % intervals of KMeans − PCA, KMeans − AE v2, PCA − AE v2 contain 0: KMeans > PCA > AE v2 is the likely order on SMD, not a settled one, and the gaps are of the same size as the spread between machines.

**Does the AE's false-alarm advantage survive? Yes.** Every retrained run stays at or below 1.21 false alarms per machine per day against E1's 3.46 (KMeans) and 3.50 (PCA); over machines AE v2 has the fewest false alarms in 100.0% of resamples and the 95 % intervals of KMeans − AE (+1.12 to +3.59) and PCA − AE (+1.07 to +3.85) exclude 0.

- **Across seeds** (3 seeds) AE v2 composite F1 is 0.516 ± 0.002 (range 0.515–0.518) against E1's 0.523, and false alarms are 1.18 ± 0.03 per machine per day (max 1.21). Every run stays below E1's PCA (0.554) and KMeans (0.596), so the AE's place at the bottom of the E1 ranking does not depend on the seed; every run also keeps fewer false alarms than KMeans (3.46) and PCA (3.50). KMeans and PCA were not retrained here (their seed-42 E1 numbers are the comparison).

- **With the held-out threshold** (3 seeds) AE v2 composite F1 is 0.505 ± 0.019 (range 0.487–0.526) against E1's 0.523, and false alarms are 0.61 ± 0.09 per machine per day (max 0.71). Every run stays below E1's PCA (0.554) and KMeans (0.596), so moving the threshold to held-out data does not lift the AE above PCA or KMeans; every run also keeps fewer false alarms than KMeans (3.46) and PCA (3.50). Only the AE threshold moved to held-out data; KMeans and PCA keep their E1 thresholds.

- The global held-out threshold is 4.52–8.11, 3.3x the threshold from all train windows (1.91–2.05 in part 1): the last 20 % of each machine's train series scores higher than the first 80 % the model was fitted on (the held-out windows are centred on the train mean, like train windows in production, so slow drift inside the train period raises their error). The held-out alarm is therefore stricter: it catches fewer faults and raises fewer false alarms than part 1.

- With **per-machine** held-out thresholds AE v2 gets composite F1 0.460 ± 0.010 at 1.70 ± 0.06 false alarms per machine per day (secondary; production uses one global threshold).

- **Bootstrap over machines** (point estimates equal E1 for Tier 2 KMeans (recenter 24), Tier 2b PCA (recenter 24); not for Tier 3 AE v2, see the note in part 3): KMeans 0.494–0.677, PCA 0.439–0.646, AE v2 0.470–0.585 (95 %). The full order KMeans > PCA > AE v2 holds in 69.0% of resamples. KMeans − PCA = +0.042 [-0.004, +0.091], not separated (interval contains 0); KMeans − AE v2 = +0.071 [-0.018, +0.144], not separated (interval contains 0); PCA − AE v2 = +0.030 [-0.069, +0.106], not separated (interval contains 0). AE v2 has the fewest false alarms in 100.0% of resamples (KMeans minus AE: +1.12 to +3.59; PCA minus AE: +1.07 to +3.85 false alarms per machine per day, 95 %).

Caveats: three seeds give a rough spread only (std over 3 values); the bootstrap treats the 28 machines as the
sampling unit and keeps each machine's test series whole, so it measures how much the result depends on which
machines are in SMD, not on which faults; it uses the fixed E1 models and thresholds, so it does not include
training noise (that is what parts 1 and 2 add). All on one dataset (SMD).

## 3. Bootstrap over machines (E1 scores, no retraining)

Scores layer `data/robust/e1_rebuild/data/scores/source=smd` (141,708 test windows, 28 machines; PCA threshold 1.08172 from `data/robust/e1_rebuild/models/pca_smd/thresholds.json`). The machines are resampled with replacement 1000 times (numpy `default_rng(0)`), the same draw for every detector (paired), and composite F1 and false alarms per machine per day are recomputed from the summed per-machine counts, which gives exactly the `evaluate` totals for the original 28 machines. 95 % interval = 2.5th–97.5th percentile.

**Note.** This is not the production `data/scores/source=smd` (it was not on the machine that ran this).
